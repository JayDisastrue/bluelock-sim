# Gemini prompts for creator part sheets

Paste the **STYLE + LAYOUT block** first in every message, then ONE sheet prompt. One sheet per message.
Parts are drawn on a flat **magenta (#FF00FF) head silhouette** so they come out isolated: the magenta is keyed out afterwards and only the part stays, already aligned. Never use magenta in a design.

## STYLE + LAYOUT block
```
Create a character-creator PARTS SHEET. Original designs only, not any existing character.

ART STYLE: the look of the Blue Lock TV anime: sharp, angular, athletic shonen sports-drama. Confident dark ink linework with strong line-weight variation (thick on outer contours, hair silhouettes and upper eyelids; hair-thin for strands and detail). Hard-edged cel shadows in one or two tones, no gradients, no soft airbrushing, no glossy or 3D rendering. Hair is drawn as sharp separate clumps and blades with a few fine strand lines inside each clump, hard shine shapes, strong silhouette. Eyes: heavy thick upper lash line with small outward flicks, large iris with a darker ring, a hard-edged white highlight, tiny intense pupil. Eyebrows sharp and angular. Faces have a defined narrow jaw and chin, not round or cute, not chibi, not generic moe.

CRITICAL, PARTS ONLY: every cell shows ONLY the listed part drawn on a flat solid magenta (#FF00FF) head-and-neck silhouette. The magenta silhouette has NO face features, NO skin colour, NO shading, NO outline, NO ears, NO eyebrows, NO eyes, NO nose, NO mouth. Draw nothing except the one listed part. Never draw a face, a skin-coloured head, a body or clothes unless the sheet says so.

LAYOUT (strict): a perfectly regular grid of equal SQUARE cells on a plain white background, thin light-grey cell borders, no text, no numbers, no labels, no watermark. In EVERY cell the magenta head silhouette is identical: same size, same position, perfectly frontal, symmetrical, its width is 50% of the cell width, its top edge is at 15% of the cell height, its chin at 78%, centred horizontally, with a short neck. Draw each part in its true position relative to that head, as if the head were wearing it. Leave a margin so nothing touches the cell border. Fill cells left to right, top to bottom. Cell 1 is always the EMPTY silhouette (nothing on it), used as the alignment reference.
```

## If it goes wrong
- **Heads or faces appear anyway:** append `Remember: ONLY the part on the flat magenta silhouette. If any cell contains a face, skin tone, ears or eyes that are not the requested part, redo that cell.`
- **Heads drift in size or position between cells:** append `Every magenta head must be pixel-identical in size and position to cell 1. Redo the sheet keeping the head exactly the same in all cells.`
- **Too anime-generic:** append `Sharper and more angular, harder shadows, heavier ink, more intense: gritty sports-drama, not soft or cute.`
- Do 8 cells instead of 16 for any sheet where the detail is poor.

## Processing a sheet (`scripts/slice_sheet.py`)
Originals are kept in `docs/part-sheets/`. The slicer finds the cell grid, keys out the magenta, drops the head outline (using the empty cell 1 as the reference), scales every cell to the template (head top y=290, ear to ear 540 px) and writes aligned 1000x1300 layers. Needs `pip install pillow numpy scipy`.
```
python3 scripts/slice_sheet.py docs/part-sheets/hair_a.webp --cols 5 --rows 4 --slot hair --ids empty,spiky,swept,shaggy,fringe,buzz,undercut,curly,long,side_part,mohawk,bob,ponytail,slick_side,messy_part,topknot,wavy,pixie,afro,-
python3 scripts/slice_sheet.py docs/part-sheets/hair_b.webp --cols 5 --rows 4 --slot hair --ids empty,braid,sweep_fringe,twin_tails,crop_fringe,slick_back,bedhead,bowl,dreads,shaved_sweep,long_bangs,wolf,half_bun,asym_long,asym_sweep,short_cut,shag_wolf,messy_bun,spike_shaved,long_sweep
python3 scripts/slice_sheet.py docs/part-sheets/eyes.webp --cols 3 --rows 3 --slot eyes --keep-box 150,500,850,860 --ids empty,sharp,round,narrow,droopy,upturned,wide,almond,heavy_lid
npm run assets:scan
```
Gemini does not always follow the cell count (it made 20 cells instead of 16), so read the sheet and list one id per cell in reading order; `-` skips a cell. Because every sheet's head geometry comes from the same prompt, hair, eyes, brows and so on line up with each other. The eye line lands near y=685 on the canvas, not at the 580 drawn on `_template.png`; the drawn SVG placeholders and the template guide use the older proportions, so mix drawn and imported parts only until the face sheet is imported.
