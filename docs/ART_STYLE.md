# Art style sheet (for original characters)

Use one fixed style block for every generation so the cast looks consistent, and so your own imports sit comfortably next to them. These prompts are for the **original** characters (and your player), not for characters from existing series.

## Style block (paste before every character prompt)
> Original character, anime sports-drama style, clean confident ink linework with slightly varying line weight, cel shading with one flat shadow tone and a small rim highlight, saturated but not neon palette, expressive large eyes, defined hair strands in 3–4 clumps, simple football (soccer) training kit with one team colour and one accent, front-facing three-quarter view, waist-up, head near the top of the frame, neutral studio pose, plain solid white background (no scenery, no text, no logo), full figure centered, 2:3 portrait.

Generate at 1200×1800 (or the closest 2:3), then remove the background to PNG. Keep head size and position identical across the set. Generate expression variants by re-using the same prompt and changing only: "expression: furious / smirking / shocked / despairing".

## Consistency checklist
Same head height and eye line · same line weight · same shadow tone · white background removed to transparency · no text or logos · file named `<id>.png`.
