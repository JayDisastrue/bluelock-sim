# Character art

**Format:** PNG (or WebP) with a **transparent background**, one character per image.
**Size:** 1200 × 1800 px (2:3). Minimum 800 × 1200. Keep each file under 2 MB.
**Framing:** front or ¾ view, head near the top (about 4–5% padding), eyes about 17% from the top, waist-up or full body. The game crops to roughly the upper 60%, so keep the important parts (face, hands, jersey) above the waist. Use the *same head size and position for every character* so they line up on screen.

**Name the file after the character id:** `sora.png`, `bachira.png`, … and `player.png` for your own character.
**Optional expression art:** `sora_furious.png`. Emotions: `neutral smirk furious shocked despair flow metavision devoured`. Any emotion you don't supply falls back to the plain `<id>.png`.

Then run `npm run assets:scan` and refresh. Full guide: `ASSETS.md`.
